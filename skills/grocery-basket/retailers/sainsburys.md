# Sainsbury's (sainsburys.co.uk)

Tested live: no (read-only study, 10 Nov 2026)

| | |
|---|---|
| Market and currency | UK, GBP |
| Search | `https://www.sainsburys.co.uk/gol-ui/SearchResults/<phrase>`, which redirects to `https://www.sainsburys.co.uk/groceries/search?searchTerm=<phrase>` |
| Add button | `Add <product name> to basket` |
| Own brand | Sainsbury's; Taste the Difference (premium); Inspired to Cook |
| Loyalty | Nectar. "Nectar price" offers need the user's linked card; never type a Nectar number. |
| Basket | "Trolley" in the header |

## Searching and adding

- Each card has two buttons with the product name: `Add to favourites: <name>` and `Add <name> to basket`. Use only the second.
- The header has an **Empty trolley** button. Never press it.
- Results include sponsored cards (the first result for "red peppers" was a sponsored jar of olives). Check the name before adding.

## Loose produce

Loose items (for example "Sainsbury's Root Ginger Loose", "Sainsbury's Onions Loose") have a radio pair, **items** or **kg**, above the Add button. **items** is selected by default. Leave it on items and add by count. Fixed items such as "Sainsbury's Red Pepper" are sold each.

## Prices and units

Cards show the price and a unit price: "80p / ea", "£5.60 / kg". Nectar offers show two prices; the lower one needs Nectar.

## Minimum basket and charges

From Sainsbury's help pages and 2026 press reports: the minimum order for home delivery rose to £50 in April 2026; reports differ on the charge below it. Delivery charges vary by slot, and a Delivery Pass removes them on qualifying orders. Read the actual charge on the basket page and mention it if the total is close to £50.
